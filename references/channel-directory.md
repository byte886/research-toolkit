## 八、选择策略（怎么按问题选渠道）

| 问题特征 | 优先渠道 |
|---|---|
| 中文语境/国内政策数据 | 国内组（豆包/DeepSeek/文心/通义/智谱/Kimi/元宝）+ 百度/秘塔 |
| 需要引用/可验证证据 | Perplexity / ChatGPT Search / Consensus / Elicit |
| 实时动态/社媒情绪 | Grok（X 数据）/ 抖音/小红书站内 |
| 长文档/论文/财报 | Kimi / Claude / NotebookLM |
| 学术/专利 | Google Scholar / arXiv / Semantic Scholar / Google Patents |
| 开发/技术排错 | Phind / ChatGPT / Claude / GitHub |
| 多源交叉（L3 深度） | Google + Grok/Claude/ChatGPT + DeepSeek/豆包 + Perplexity（默认组合） |
| 免费优先 | 豆包/DeepSeek/Kimi/秘塔/天工（国内免费额度大） |
